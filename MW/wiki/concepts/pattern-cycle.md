# Pattern Cycle

**Definition:** [[alan-farley]]'s framework that markets move through a **repeatable sequence of phases**
on every timeframe (fractal): **bottoms → breakouts → rallies → highs → tops → reversals → declines** →
back to bottoms. Knowing which phase a stock is in dictates which tactic applies.

## Key axes
- **Trend–Range Axis:** price is either **trending** (directional) or **ranging** (rotational); tactics
  differ — breakouts/pullbacks in trends, fades at edges in ranges.
- **Expansion–Contraction:** volatility **cycles** between quiet contraction (tight bases) and active
  expansion (the move). Contraction precedes expansion — the basis of the **Coiled Spring** ([[seven-bells]])
  and a direct cousin of [[vcp]].
- **3D charting / Trend Relativity:** read **three timeframes**; the same bar means different things in
  different frames.

## Why it matters
- Stops you from applying a trend tactic in a range (or vice-versa). Tells you whether a Key List name is
  in a *buyable* phase (base/breakout/first-pullback) or a *late/topping* phase (sell into strength).

## How it connects
- Setups that act on each phase: [[seven-bells]]. Confluence of S/R within a phase: [[cross-verification]].
- Maps to the wiki: contraction→expansion = [[vcp]]; breakout phase = [[pyramid-50-30-20-strategy]] adds;
  topping/decline = [[selling-into-strength]] / exits.
