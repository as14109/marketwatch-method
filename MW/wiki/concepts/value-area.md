# Value area

**Definition:** In [[market-profile]], the price range covering the **first standard deviation of volume
(~70%)** for a session — the zone where the most trade occurred and the market deemed "fair." The key
reference point for [[auction-market-theory]].

## Use
- **Reference for initiating vs. responsive** (vs. the *previous* day's value area):
  - buy **below** value / sell **above** value = **responsive**;
  - buy **above** value / sell **below** value = **initiating**.
- **Value migration** (today's value vs. yesterday's: higher / lower / overlapping) signals trend vs.
  balance — overlapping value = rotational; clearly higher/lower value = directional.
- **Point of control** (highest-volume price) sits inside the value area as the fairest price / magnet.

## How it connects
- Part of [[market-profile]]; reference for [[auction-market-theory]]; inventor [[peter-steidlmayer]].
- Practical tie-in: a Key List pivot far **above** the prevailing value area is an extended/initiating buy
  (size down per [[key-list-trade-rules]]); a pullback **into** value can be a lower-risk responsive entry.
